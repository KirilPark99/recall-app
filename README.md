# 🧠 Recall — Self-Hosted сервис для изучения по карточкам

**Recall** — это полнофункциональный автономный self-hosted веб-сервис для создания, организации и эффективного изучения учебных материалов по карточкам (современная замена Quizlet).

Сервис спроектирован для персонального использования, семей или учебных групп на собственном сервере. Не требует сторонних облаков или платных подписок: всё хранится локально в SQLite с поддержкой полнотекстового поиска (FTS5) и режима WAL.

---

## ✨ Основные возможности

### 📚 7 режимов занятий
1. **Карточки (Flashcards)** — классический просмотр с 3D-переворотом, автоозвучкой и удобным управлением с клавиатуры (пробел, стрелки, 1-4).
2. **Обучение (Learn)** — адаптивный интеллектуальный режим с разбивкой материала на настраиваемые порции (батчи), кругами повторения и автоматической доработкой ошибок.
3. **Письменный ответ (Write)** — проверка орфографии и точного ввода с наглядным сравнением ответа, подсветкой ошибок и возможностью перезачета.
4. **Диктант (Spell)** — аудирование и ввод терминов на слух с регулируемой скоростью речи.
5. **Тест (Test)** — генерация комплексных тестов с 4 типами вопросов (выбор варианта, истина/ложь, соответствие, письменный ответ), черновиками и опциональным таймером.
6. **Подбор пар (Match)** — сопоставление терминов и определений на время со штрафными секундами и таблицей рекордов.
7. **Интервальное повторение (FSRS)** — передовой научно обоснованный алгоритм *Free Spaced Repetition Scheduler* (FSRS 6.x). Направления «прямое» (вопрос → ответ) и «обратное» (ответ → вопрос) отслеживаются как независимые единицы памяти.

### ⚡ Продвинутый импорт из Quizlet и файлов
- **Прямой импорт по ссылке:** вставьте ссылку на любой публичный набор или целую **папку Quizlet** — сервис автоматически скачивает все карточки, обходя защиту Cloudflare через встроенную интеграцию с EzSolver.
- **Импорт текста:** интеллектуальное определение разделителей (табуляция, дефис, двоеточие, запятая, чередование строк).
- **Импорт файлов:** поддержка форматов CSV, TSV, JSON и TXT с предпросмотром, дедупликацией и валидацией строк.
- **Экспорт:** выгрузка наборов в форматах JSON, CSV, TSV и переносимых архивах.

### 📁 Папки и организация материалов
- Организация наборов по папкам, поддержка нераспределенных наборов («Без папки») и общего каталога.
- **Удобная плавная горизонтальная прокрутка вкладок:**
  - Поддержка вертикального колесика мыши (автоматическая конвертация в горизонтальный скролл).
  - Кнопки плавной навигации `<` и `>` с динамическим отображением.
  - Мягкие градиентные маски переполнения.
  - Поддержка протягивания мышью (Drag-to-scroll).
  - Автоматическая центровка активной вкладки.
- Административное назначение общих папок конкретным пользователям сервера.
- Полнотекстовый поиск по содержимому всех карточек (SQLite FTS5).

### 🎙️ Естественная нейроозвучка (Neural HD) и медиа
- Поддержка студийного человеческого произношения (Neural HD) для языков без роботизированного акцента.
- Автономный Web Speech API fallback без внешних зависимостей.
- Прикрепление изображений и аудиофайлов к карточкам.

### 🛡️ Безопасность и администрирование
- Аутентификация на серверных HttpOnly-cookie с защитой от CSRF.
- Панель управления пользователями, ролями (`admin` / `user`) и блокировками.
- Мониторинг активных сессий устройств с возможностью удаленного отзыва.
- Создание и восстановление резервных копий (Backup / Restore) через встроенный CLI.
- Настройка прокси для работы с Quizlet в регионах с ограничениями.

### 📱 Адаптивный и доступный интерфейс
- Полная адаптивность для мобильных телефонов, планшетов и настольных компьютеров.
- Мобильная нижняя навигация с учетом безопасных зон (iOS Safe Area).
- Светлая, тёмная и системная темы оформления.
- Поддержка локалей (Русский и English).

## 🚀 Быстрый запуск

### Системные требования
- Python 3.12 или новее
- Node.js 20 или новее (npm)
- Любая современная ОС (Linux, macOS, Windows/WSL2)

### 1. Клонирование репозитория
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd SelfHostedQuizlet
```

### 2. Настройка конфигурации (.env)
Скопируйте файл с примером настроек:
```bash
cp .env.example .env
```
*(При необходимости отредактируйте `.env`, например укажите `DATA_DIR=./data` и параметры лимитов).*

---

### 3. Установка и запуск бэкенда

Создайте виртуальное окружение и установите зависимости:
```bash
# Создание venv
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей бэкенда
pip install -e './backend[dev]'

# Применение миграций базы данных
cd backend
alembic upgrade head
cd ..
```

Создайте учётную запись администратора:
```bash
# Вариант 1: Интерактивный ввод (пароль скрыт при вводе)
python3 -m backend.app.cli create-admin

# Вариант 2: Прямое указание логина и пароля через аргументы
python3 -m backend.app.cli create-admin --username admin --password mypassword123

# Сброс/смена пароля любого пользователя или администратора при необходимости:
python3 -m backend.app.cli reset-password --username admin --password newpassword123
```

Запуск сервера бэкенда:
```bash
uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload
```
API бэкенда будет доступно по адресу: `http://127.0.0.1:8000` (документация: `http://127.0.0.1:8000/api/docs`).

---

### 4. Установка и запуск фронтенда

Во втором терминале перейдите в папку `frontend`:
```bash
cd frontend
npm install
npm run dev
```
Интерфейс приложения будет доступен по адресу: **`http://localhost:5173`** (все запросы к `/api` автоматически проксируются на бэкенд `:8000`).

---

### 5. Удобный одновременный запуск (Dev-скрипт)

В корне проекта есть готовый скрипт для запуска обоих сервисов в один клик:
```bash
chmod +x scripts/dev.sh
./scripts/dev.sh
```

## 📦 Production сборка

Для развертывания в рабочей среде соберите статику фронтенда:
```bash
cd frontend
npm run build
```
Собранные файлы попадут в `frontend/dist/`. FastAPI автоматически раздает собранный SPA и API на одном порту `8000`:
```bash
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --workers 1
```

Для внешнего доступа рекомендуется настроить обратный прокси (Nginx или Caddy) с поддержкой SSL/HTTPS.

## 💾 Резервное копирование и восстановление

Встроенный CLI позволяет создавать согласованные горячие копии базы данных и медиафайлов:

```bash
# Создание резервной копии
python3 -m backend.app.cli backup create --output data/backups/recall-backup-$(date +%F).tar.gz

# Проверка целостности архива
python3 -m backend.app.cli backup verify data/backups/recall-backup-YYYY-MM-DD.tar.gz

# Восстановление (выполняется при остановленном сервере)
python3 -m backend.app.cli backup restore data/backups/recall-backup-YYYY-MM-DD.tar.gz --confirm
```
