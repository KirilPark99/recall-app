# План реализации

Порядок — вертикальные срезы; после каждого этапа — проверки, фиксация в PROGRESS.md.

| Этап | Объём | Критерий готовности |
| --- | --- | --- |
| 1. Основа | конфиг, БД, миграции, auth (сессии+CSRF), CLI create-admin, каркас UI, ru/en, темы, health/ready | чистая установка открывается; вход работает |
| 2. Карточки | CRUD наборов/карточек, папки, теги, избранное, поиск, режим Cards | материал создаётся в UI, проходится, живёт после restart |
| 3. Редактор и перенос | автосохранение, 409-конфликты, массовые операции, reorder, media upload, импорт preview/commit, экспорт | импорт → правки → экспорт → импорт сохраняют поля |
| 4. Проверяемое обучение | общий механизм занятий, снимки, AnswerChecker, генератор вопросов, Learn, Write, Spell | у каждого режима завершённый путь и достоверный итог |
| 5. Test и Match | черновики, deadline, история попыток; доска пар, штрафы, рекорды | результат считает сервер; restart не обнуляет и не удваивает |
| 6. SRS и статистика | FSRS-адаптер, enrollment, направления, очередь, лимит новых, undo, reset; главная, цели, статистика | retry/конфликт вкладок не ломают состояние; тренировки не меняют FSRS |
| 7. Sharing и админка | permissions, каталог, share links + redeem/revoke, админ-раздел, блокировка | owner/reader/посторонний видят только своё |
| 8. Эксплуатация | production-раздача SPA, jobs, backup/restore CLI, README/OPERATIONS | restore поднимает рабочий экземпляр |
| 9. Приёмка | тесты (pytest, typecheck, build), ручной smoke, ACCEPTANCE.md, финальный отчёт | матрица приёмки заполнена реальными свидетельствами |
