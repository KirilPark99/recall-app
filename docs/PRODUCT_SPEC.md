# Recall — продукт

Recall — self-hosted сервис для изучения материала по карточкам (аналог Quizlet по принципам работы, собственный по названию, дизайну и реализации).

## Пользователи

- `admin` — владелец сервера: управляет аккаунтами, регистрацией, лимитами, backup.
- `user` — изучающий: свои наборы, папки, прогресс, статистика.

Регистрация по умолчанию выключена; первого администратора создаёт CLI (`python -m app.cli create-admin`).

## Главный путь

1. Вход → рабочая среда (без маркетингового лендинга).
2. Создание набора вручную или импорт CSV/TSV/JSON/текста/ZIP.
3. Редактор с автосохранением, защитой от конфликтов версий, массовыми действиями.
4. Выбор режима занятия на странице набора.
5. Занятие с серверной проверкой ответов и снимком материала.
6. Разбор результатов; продолжение незавершённого занятия после перезагрузки.
7. SRS-повторение (FSRS) и статистика с дневной целью.
8. Sharing (прямые разрешения, ссылки), импорт/экспорт, backup.

## Режимы занятий

| Режим | Суть | Влияние на SRS |
| --- | --- | --- |
| Карточки (Cards) | просмотр, переворот, самооценка «Знаю / Пока не знаю» | нет |
| Обучение (Learn) | адаптивная тренировка: распознавание → письменное воспроизведение, порции до 10, освоение = 2 успешных подряд | нет |
| Письменный ответ (Write) | ввод ответа, проверка на сервере, подсказки, ручная коррекция | нет |
| Диктант (Spell) | аудио/TTS → ввод услышанного | нет |
| Тест (Test) | до 100 вопросов, типы: выбор, письменный, верно/неверно, сопоставление; черновики; таймер | нет |
| Подбор пар (Match) | доска 6/8/12 пар, штраф 3 с за ошибку, личный рекорд по fingerprint | нет |
| Повторение (SRS) | оценки «Не помню / Трудно / Помню / Легко», FSRS | да |

## Навигация

Главная · Мои наборы · Папки · Повторение · Статистика · Общие наборы · Настройки · Управление сервером (admin).

## Языки и темы

- Интерфейс ru (по умолчанию) / en, переключение в настройках; карточки не переводятся.
- Темы light / dark / system.

## Терминология

- `side` = front/back — сторона контента.
- `direction` = front_to_back / back_to_front — направление воспоминания; `both` — настройка выбора, а не отдельное SRS-состояние.

## Границы

Без подписок, платных API, внешних LLM, облачных аккаунтов. Работает без интернета при доступности сервера. Не входит: совместное редактирование в реальном времени, анонимное чтение, PWA-синхронизация.
